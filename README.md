# SkyFitnessPro

## Описание проекта

SkyFitnessPro — это веб-приложение для фитнес-курсов, разрабатываемое командой от верстки до деплоя. Приложение предоставляет пользователям возможность просматривать доступные курсы, регистрироваться, проходить тренировки и отслеживать свои успехи.



### Основные функции:

    Страница курсов с отображением всех доступных курсов.
    Авторизация и регистрация с Firebase.
    Страница профиля для управления данными пользователя.
    Страница отдельного курса с возможностью добавления в профиль.
    Страница тренировки с отслеживанием прогресса и доступом к материалам.



### Технологии

- **TypeScript**: основной язык для разработки.
- **React.js**: для построения пользовательского интерфейса.
- **Tailwind CSS**: библиотека для стилизации компонентов.
- **Google Firebase**: используется для хранения данных и аутентификации пользователей.
- **Netlify**: платформа для деплоя.
- **ESLint и Stylelint**: линтеры для соблюдения стиля кода.
- **Jest и React Testing Library**: для написания тестов и проверки функциональности.



### Основные страницы и функционал

#### 1. Главная страница курсов

- На главной странице отображаются все курсы, доступные в базе данных. Доступ к ним не зависит от авторизации. 
- На карточке также есть кнопка добавить курс, если незарегистрированный пользователь нажимает на неё, то его перенаправляет на окно входа в приложение. 
- По клику на выбранный курс пользователь попадает на страницу, где может ознакомиться с его описанием. 
- Кнопка «Наверх» выполняет скроллинг к началу страницы.

#### 2. Страница авторизации/регистрации

- Позволяет пользователям войти в приложение или создать новый аккаунт. 
- В случае некорректного ввода данных отображается соответствующее сообщение об ошибке.

#### 3. Страница отдельного курса

- Незарегистрированные пользователи или пользователи, не купившие курс, могут просмотреть описание курса. 
- Авторизованные пользователи могут приобрести курс или получить предложение войти в систему.

#### 4. Страница профиля

- Здесь пользователь может редактировать данные профиля, изменить пароль, а также просмотреть приобретенные курсы и начать тренировку.

#### 5. Страница тренировки

- Позволяет пользователю открыть материалы урока (видеоролики, задания) и заполнять прогресс.

## Установка и настройка

### 1. Установка. Клонирование репозитория

Склонируйте этот репозиторий на локальную машину:

bash
git clone https://github.com/HydroponKing/fitness/

### 2. Настройка

### Установка зависимостей
Убедитесь, что вы находитесь в корневом каталоге проекта и выполните:

**Добавление и просмотр курсов.**
**Отслеживание прогресса тренировок.**
